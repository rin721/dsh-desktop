# 上游兼容的 Windows 桌面应用

[English](README.md) | 中文

## 范围

本变更记录定义 DeepSeek Harness 的 Windows 桌面发行方案：上游仓库保持为未经修改、可替换的依赖，同时交付可安装应用、独立窗口、生命周期监管、打包能力和基于证据的上游更新路径。

主路线使用独立桌面伴生仓库和精确版本的官方 `@deepseek-ai/dsh` npm 发布物。后续可以选择向上游贡献一个受支持的小型进程控制契约，以替换兼容性监管适配器，但这不是首个桌面版本的前置条件。

## 状态

状态：提案阶段，等待实施确认。

本目录仅包含计划，不授权修改应用代码、安装依赖、执行打包或签名、发布产物，也不授权修改上游 DeepSeek Harness 运行时。

## 文档归属

本变更目录负责记录拟议工作及其执行证据。在桌面应用实际存在之前，不提前改写描述当前事实的主题文档。

实施被接受并验证后，实施变更必须更新 [architecture.md](../../architecture.md)、[development.md](../../development.md) 和相关子系统页面（例如 [web-server.md](../../subsystems/web-server.md)），使已交付行为只有一个长期有效的事实归属。实施引入的架构决策还必须通过仓库的 Agent Note 流程记录，而不能把本任务记录变成永久的当前状态文档。
